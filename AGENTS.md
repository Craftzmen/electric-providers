## Cursor Cloud specific instructions

- Install dependencies with `npm ci`. The lockfile is `package-lock.json`.
- Start the app with `npm run dev -- --hostname 0.0.0.0 --port 3000`.
- Open the site at `http://localhost:3000`. Next.js 16 blocks development resources, including client hydration, when the host is `127.0.0.1`.
- `npm run lint` and `npm run build` are the project checks. `next-env.d.ts` is gitignored and is generated by `next dev` or `next build`.
